# hed-repos-admin

A temporary repository for managing the HED-related repositories while they are being standardized.

It holds one committed document that matters: [`REPOS.md`](REPOS.md), the map of the repositories - each one's purpose, its cluster, what it owns, and what it depends on. The working plans that span more than one repository live in the gitignored `.status/` directory and exist only on the machine doing the work.

This repository holds no code, belongs to no repository cluster, and grants no standing access to any other repository.
